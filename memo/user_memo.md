## 自明な因果グラフ（gemini）

1. 環境 (Lv0) が 状態 (Lv3) に与える直接的因果
環境の変化は、人間の恒常性（ホメオスタシス）を維持するためのバイタル変動を強制的に引き起こします。

温度・湿度 → 体温・血圧 (Lv3-1): 外気温が低下すると、血管が収縮し血圧 (blood_pressure) が上昇します。また、湿度の高低は発汗効率を変え、体温調節に負荷をかけます。

明るさ (照度) → 睡眠質・気分 (Lv3-1, 3-2): 夜間の明るさはメラトニン生成を抑制し、睡眠質 (sleep_quality) を低下させます。日照時間の減少（季節）は、セロトニン分泌に影響し、気分 (mood) を減退させます。

時刻 → 血糖値・血圧 (Lv3-1): サーカディアンリズムにより、起床前には活動準備のために血圧や血糖値 (blood_sugar) が自然に上昇します。

2. 不変の核 (Lv1) が 可変状態 (Lv3) を規定する因果
個体差（遺伝的・性格的素因）は、同じ環境下でも異なる反応を導きます。

クロノタイプ (Lv1-1) × 時刻 (Lv0) → パフォーマンス (Lv4): 「夜型」の人が早朝（時刻）に活動すると、睡眠質 (sleep_quality) が損なわれ、日中の体調 (context) が著しく悪化します。

苦味への感受性 (Lv1-1) → 興味の対象 (Lv4): 味覚の鋭敏さは、食習慣（マイブーム）や特定の嗜好を制限・決定します。

外向性・好奇心 (Lv1-2) → 信頼度・親しみやすさ (Lv3-2): 高い好奇心を持つ個体は、新しい情報や対人接触に対して親しみやすさ (friendliness) の上昇速度が速い傾向にあります。

3. 可変状態 (Lv3) が 長期成長 (Lv2) へ蓄積する因果
日々の流動的なデータが積み重なり、元に戻らない身体的変化を形成します。

睡眠・栄養 (Lv3-1) → 身長・骨密度 (Lv2): 成長期における継続的な睡眠時間 (sleep_time) の確保や栄養状態は、身長 (height) や骨密度 (boneDensity) の最大到達点を決定します。

体重・血糖値 (Lv3-1) → 視力 (Lv2): 長期的な高血糖状態は、血管損傷を通じて視力 (eyesight) の不可逆的な低下（糖尿病網膜症など）を招くリスクとなります。

気分・情緒 (Lv3-2) → 声の高さ (Lv2): 長期的なストレス状態や情緒の安定性は、ホルモンバランスを通じて加齢に伴う声の高さ (voicePitch) の変化に影響を及ぼすことがあります。

4. 文脈 (Lv4) と 状態 (Lv3) の相互作用
数値化しづらい「今この瞬間」の認識が、生理データにフィードバックされます。

体調 (Lv4) → 信頼度・情緒 (Lv3-2): 身体的な不快感（体調不良）があるとき、人間は他者に対する攻撃性 (Lv1-2) が一時的に高まり、信頼度 (trust) の構築が困難になります。

マイブーム (Lv4) → 睡眠・体重 (Lv3-1): 特定の趣味への没頭は、睡眠時間を削り、活動量の変化に伴い体重 (weight) を増減させます。

因果の相関図（サマリ）
原因（Lv）	結果（Lv）	自明な因果の内容
Lv0: 天気・気圧	Lv3: 気分・血圧	低気圧による気象病、気分の落ち込み
Lv1: 知能・性格	Lv4: 興味の対象	素因に合致した分野への知的好奇心の集中
Lv3: 睡眠・体温	Lv3: 健康度・情緒	睡眠不足による免疫力低下と感情制御の不安定化
Lv3: 体脂肪率	Lv2: 最大筋力	体格組成の変化に伴う物理的な出力限界の変化
これらの因果は、AI人格を設計する際、Lv0（外部刺激）を入力としたときに、Lv1（フィルター）を通ってLv3・Lv4（反応）がどう動くべきか、というロジックの根拠となります。
