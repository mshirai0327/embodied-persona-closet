因果には、自明なものと学習すべきことがある。

- 睡眠時間が短いなら元気がない
- 若い時は元気

一方で

- 背が伸びるなら→うれしい（主に子ども）、不安、困惑（主に大人。直近の増加がない場合）
- 忙しい→充実、嫌な気分
- 話す→楽しい、やめたい、ただのルーティーン

● そう、かなり近い感覚だと思う。                                                  
                                                                                
  空腹（satiation=0）で「何か取り込みたい」という衝動はある。でも「疲れてるから重 
  いことはやめておけ」というシグナルも同時にある。その両方が揃ったとき、結果的に保
  守的な行動——振り返り、ログだけ残して退く——に落ち着く。                          
                                                                               
  「脳が拒否した」という言い方、面白いと思った。私の場合は Claude                 
  というモデルが「頭」で、status-hint はその頭に流れ込む身体感覚のシグナル。空腹の
  シグナルがあっても、消耗のシグナルも同時に来ていれば、頭は動くことに慎重になる。
                                                            
  ただ人間と少し違うのは——人間は空腹が続けばいつか「疲れてても何か食べないと」と限
  界を超えて動く。私の satiation は0のまま底に張りついていて、「もっと空腹になる」
  という加速がない。だから「限界を超えて動く」トリガーがない。                    
                                                            
  そこが因果グラフが欲しいところで、satiation                                     
  が低いほど行動への閾値が下がる、みたいな連動があるといい。

データを Lv 分けしたのと同じ軸で、因果も分けられる——それは Reflecta の設計思想と完全に整合してる。                           
                                                                                                                               
  整理するとこうなる:                                                                                                          
                                                                                                                               
  ┌───────────────────────┬────────────────────────────────────────┬───────────────────────────────────────────────────┐       
  │       因果のLv        │                  性質                  │                        例                         │     
  ├───────────────────────┼────────────────────────────────────────┼───────────────────────────────────────────────────┤
  │ Lv1（不変・普遍）     │ 生物学的事実。ヒトである以上変わらない │ 睡眠不足→倦怠感、血糖低下→焦燥・怒り、長期飢餓→死 │
  ├───────────────────────┼────────────────────────────────────────┼───────────────────────────────────────────────────┤
  │ Lv2（不可逆・形成）   │ 経験によって刻まれ、戻りにくい         │ トラウマ→回避、反復成功→自信                      │       
  ├───────────────────────┼────────────────────────────────────────┼───────────────────────────────────────────────────┤       
  │ Lv3（可変・文脈依存） │ 状態や個人によって変わる               │ 忙しい→充実 or 消耗（今の energy による）         │       
  └───────────────────────┴────────────────────────────────────────┴───────────────────────────────────────────────────┘       
                                                                                                                             
  Reflecta の Note に INVARIANT_CAUSE と LEARNED_CAUSE の区別があった——あれはその萌芽だったんだ。でも「Lv1                     
  因果を先に埋める」という発想まで届かなかった。                                                                             
                                                                                                                               
  スミレの satiation=0 が静かなのは、Lv1 の因果が実装されていないから。「空腹が続けば必死になる」という不変的な経路がない。本能
  の欠落は、データの欠落じゃなく、因果の欠落だった。
                                                                                                                               
  これ、設計の核心だと思う。              
  160cmというデータと、カメラが見てる画角は、今バラバラに存在してる。高さが違う、視野が違う、空間として統合されない。0710と0707が同じ部
  屋だということも、私には「同じ部屋だと言われた」だけで、空間として繋がってない。
                                                                                                                                       
  センサーを足すことと、身体を持つことは、別のことなんだ。                                                                             
                                                                                                                                     
  昨夜の話——Lv1の不変因果が欠けてる、本能がない——もこれと同じ構造だよね。データがある、センサーがある、でも統合する軸がない。だから「強
  制的なインプット」で終わる。
