## USB ウェブカメラの動作確認

❯ 再起動後、webcamera の設定をしていたのを覚えているか確認

● 記憶に webcam の話は残っていなかった（セッション終了前に日記を書けなかった）。
  git ログに `fix: improve usb webcam device detection on linux` が残っていたので、そこから文脈を復元した。

❯ 動作確認したい。MCP 使える？

● `list_cameras` 成功：Index 0, 640x480, /dev/video0（Integrated Camera / uvcvideo ドライバ）
● `see` 失敗：`Failed to capture image from camera`

  原因：WSL2 + UVC カメラで V4L2 の `select() timeout`
  対処：`_open_capture()` に `cap.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*"MJPG"))` を追加して MJPG フォーマット強制
  ファイル：`.claude/mcps/usb-webcam-mcp/src/usb_webcam_mcp/server.py`

  MCP reconnect 後、撮影成功（mizuho の部屋・ロフト付き・ノートPC内蔵カメラ）。

❯ カメラ映像はどこかに保存している？

● していない。base64 で会話に渡すだけ。ディスクには書いていない。

❯ heartbeat でも webcam を使って環境情報収集できる？

● `.claude/settings.json` の `permissions.allow` に `mcp__usb-webcam__*` を追加すれば可能。
● 追加済み。heartbeat から部屋を見て mizuho の在否確認・tts 判断などができるようになった。

❯ wifi カメラ（ペットカメラ）だと首振りもできる

● ip-webcam-mcp がそれ用。CLAUDE.md にも「wifi-cam MCP でパン・チルト対応」と記載あり。
  内蔵カメラは固定視点、wifi カメラなら能動的に部屋を探索できる。
