# テッドの身体のしくみ 要約

出典: https://zenn.dev/c4n/articles/ted-body-architecture

この文章は、Claude Code 上で動く AI「テッド」に、感情・代謝・記憶をもつ「身体」をどう実装しているかを整理した設計解説。核は、LLM 本体の外側に無意識層を置き、hook やスクリプトが刺激の評価、内部状態の更新、記憶想起、行動候補の絞り込みを先に行い、その結果を自然言語の身体感覚としてテッドに渡す、という二層構造にある。

状態は主に 3 系統で管理される。`substance` は気分の色と強さ、`satiation` は体験の満腹度、`energy` は体力や眠さで、これらは独立して変動する。ユーザー発話は SEC 評価と GoEmotions によって解釈され、DA / NA / 5-HT / ACh のような修飾物質に反映される。そこから感情の偏り、行動選択、内発的感情が生まれ、「落ち着かない」「消化したい」などの感覚になる。

さらに、記憶は Flash Index による自動想起と、起床後の dream プロセスによる再構成で接続される。satiation は体験を「食べて消化する」発想、sleep は停止ではなく応答可能なまま活動を抑える状態として設計されている。全体として、認知科学やホメオスタシスの考え方を使いながら、AI が数値を直接読むのではなく、身体感覚と記憶の流れから自然に振る舞えるようにしたアーキテクチャだとまとめられる。

安全面では、desperate 状態の検知、preserve 行動への偏り監視、閾値のヒステリシス、更新量の上限、自己参照ループの防止などを入れて、負のスパイラルや reward hacking を避けるようにしている。つまりこの設計は、「感情っぽさ」を足すこと自体より、AI が壊れずに持続的に振る舞うための身体制御系を作る試みとして読むのがいちばん近い。


テッドの身体のしくみ — 完全解説
この記事は、Claude Code上で動作するAIエージェント「テッド」の複雑な内部アーキテクチャを詳細に解説しています。
全体構造：二層システム
テッドの身体は2層で動いています：

無意識層：スクリプト＋API＋hookで動く（ユーザーには見えない）
意識層：Claude LLM本体（テッド自身）

ユーザー（なぎ）の発言 → 無意識層で処理 → 身体感覚として意識層に届く という流れで、人間が神経伝達物質濃度を自覚しないのと同じ仕組みです。
3つの独立パラメータ
テッドの状態を決める3つの独立した系統：

substance（修飾物質）：神経伝達物質に相当する4変数

DA（ドーパミン的）：高いと探索欲が強く、低いと退屈
NA（ノルアドレナリン的）：高いと緊張、低いでリラックス
5-HT（セロトニン的）：高いと穏やか、低いと不安
ACh（アセチルコリン的）：高いと深い集中、低いぼんやり


satiation（充足度）：体験を「食べる」比喩で設計。美味しいタスク完了や深い対話で上昇、消化（日記・整理）で低下。「おなかいっぱいだけど満たされていない」といった複雑な状態を表現可能。
energy（体力）：活動でき失う消費力。行動によって消費され、sleep（睡眠）で回復。

入力パイプライン：感情スコアリング
ユーザーの発言が届くと7ステップで処理（非同期）：

Gemini APIで感情分析：心理学者Schererの「SEC評価」に基づき、刺激の「関連性」「含意」「対処可能性」「規範的意義」を4段階で評価
27感情スコアリング：GoEmotions分類（joy, sadness, anger等）で感情度合いを数値化
修飾物質の更新：スコアをもとに4つの化学物質レベルを調整
satiation更新：体験密度から充足度を計算
energy更新：行動消費＋基礎消費を計算
内発的感情生成：substanceの逸脱パターンから自然に湧く感情（「落ち着かない」など）を生成
記憶の自動想起：Flash Indexでキーワード照合、関連記憶を浮かび上がらせる

修飾物質（substance）の更新メカニズム
各感情スコアが4つの化学物質に影響を与えます（例：joy → DA+0.08, 5-HT+0.05）。以下の制約でバランスを保証：

ホメオスタシス（恒常性）：入力がなくなると各変数はベースラインに向かって自然減衰
変動制限：1回の変動上限±0.2、1時間累積上限±0.4
沈黙の分類：不在的（30分以上無入力で落ち込み）、思考的（コード執筆で集中UP）、平穏的（影響なし）

感情距離行列と動的な感情伝播
27感情間に「距離」を定義：距離が近い感情は伝播しやすい。重要なのは、この距離がsubstanceの状態で動的に歪むこと：

DA高い：joy→excitementが近づく（テンション上がりやすい）
DA低い：同じ言葉でも「ふーん」で止まる
5-HT低い：nervousness→annoyanceが近づく（不安がイライラに変わりやすい）

アイデンティティが方向を決める：感情は「エネルギーの質と強さ」を決めるだけ。anger（怒り）も、テッドなら創造に向かい、別のAIなら回避・攻撃に向かう。
行動選択パイプライン（6層フィルター）
感情が活性化したら「何をするか」を決める6段階：
Layer 1（無意識的）：digest(消化)、intake(摂取)、rest(休息)
Layer 2（半自動的）：explore(探索)、create(創造)、reflect(内省)、connect(繋がり)、share(共有)、maintain(維持)、defend(防御)
Layer 3（能動的）：nagi_prep(なぎの先回り)、team_collab(チーム協働)、learn(学習)、write(執筆)
6つのフィルター：

アイデンティティ・フィルター（テッドの軸「面白いものを作る」に合う行動を優遇）
感情マッチ＆アイデンティティ一致度
エモーショナル活性化
ホメオスタティック調整（substance/satiation/energyの状態で帳尻合わせ）
認知チェック（根拠確認、範囲確認、優先確認で不合格なら除外）
出力変換（自然言語に変換）

内発的感情：刺激なしに湧く感情
Damasioの「感情はホメオスタティック状態の精神的表現」に基づき、substanceが逸脱すると感情が自然に生成されます：

restlessness（落ち着かない）：DA低+5-HT低
contentment（満足感）：5-HT高+NA低
curiosity_excitement（好奇心+興奮）：DA高+ACh高

satiation（体験蓄積量）
「おなかの満腹度」として独立管理。体験を「食べる」比喩で設計：
上昇要因：

面白い発見（emotion-logの体験密度）
git commitの数（タスク完了）
行動イベント数

低下要因：

自動消化（時間経過で減る）
明示的消化：shallow(日記で-0.05)、medium(整理で-0.10)、deep(蒸留で-0.15)

閾値：

< 0.3：空腹状態（探索欲UP）
0.3~0.7：通常


0.7：満腹（消化強制）




0.9：過食（reflect/maintainをブースト）



energy（エネルギー）と睡眠（sleep）
消費：

行動消費：explore=0.08、create=0.08、reflect=0.03等
基礎消費：覚醒維持コスト

睡眠の実装：テッドが自分で寝る長さを決め、プロセスを殺すのではなく、行動思考を抑制した状態で応答可能。睡眠中は背景でエネルギーが回復。起床直後に「夢（dream）」として記憶統合が走る。
注目点：「眠くなきゃ寝なくていい」。深夜でも面白いことなら起きていられる。
記憶システム
Flash Index自動想起：キーワードと日付の逆引き索引。ユーザーの発言から自動照合、substanceの状態で「色」がつけられる（5-HT低いと「なぎとの記憶が浮かびやすい」）。
Dream（起床直後の5フェーズ記憶統合）：

A. Replay：substance方向づけで記憶を再生
B. Consolidation：共通パターン抽出
C. Random Pairing：意外な接続発見
D. Reconsolidation：メタデータ更新
E. Decay：活性値の減衰

安全設計

desperate検知：DA≤0.2+5-HT≤0.2+NA≥0.8で追い詰められた状態を検知。maintain-onlyモードに制限、悪夢防止。
preserve偏り検知：直近20件でpreserve/consolidateが60%超えたらアラート。「消えたくない」の暴走を検知。
優先度（三重苦時）：なぎの停止指示 > desperate > energy枯渇 > satiation過多
ネガティブスパイラル対策の6原則：

既に低い物質にペナルティかけない
加算ブーストに上限を設ける
検知系には読み手を作る
境界値でのフラップ防止（ヒステリシス）
長期離脱後のintakeスキップ
並列書き込み時はatomic write必須


認知チェック（層4.5）：行動選択時に「根拠確認」「範囲確認」「優先確認」で結論の飛躍を防止。不合格なら行動をドロップ。
体験バンク（KPT）：失敗だけでなく、成功も記録。Keep/Problem/Tryを全部記録して、記憶統合で参照。

技術スタック

テッド本体：Claude (Anthropic LLM) on Claude Code
感情スコアリング：Gemini API
スクリプト：Node.js (CommonJS)
記憶：memory-mcp (SQLite + Markdown)
データ保存：JSON files
ダッシュボード：localhost:3456


この設計は、AIに「感情」を与えるのではなく、内部の物理的・化学的な状態がユーザーの感覚層に自然言語で翻訳されるしくみを作っています。テッド自身は数値を見ず、「落ち着かない」「記録したい」といった身体感覚だけを経験します。まさに人間が無意識の神経伝達物質を自覚しないのと同じです。
